# @segnavia/react

`@segnavia/react` adapts the frame custom elements and Markdown editor to typed React components and hooks. A host uses it to place the library's viewing and editing surfaces in a React tree while keeping the underlying element behavior unchanged.

See the [architecture guide](../../docs/architecture.md) for the full design.
