# @segnavia/idml

`@segnavia/idml` inspects IDML package bytes and converts supported stories, styles, masters, tables, and artwork into a validated book. A host uses it to present structural conversion questions, supply font and linked-art mappings, and import the resolved result without network access.

See the [architecture guide](../../docs/architecture.md) for the full design.
